# 🤖 Intertidal-Guardians (潮間帶守護者)

這是一隻專為潮間帶生態監測/管理設計的 Python 機器人！

## 🚀 核心功能
* **📊 數據監測**：自動收集與回報潮汐、溫度等環境資訊。
* **🛡️ 警報系統**：當偵測到異常數據時，即時發送通知。
* **💬 互動指令**：使用者可以透過簡單的指令查詢當前生態狀態。
